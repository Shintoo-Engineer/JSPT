# ✝️ JSPT — Jesus Saves Prayer Team
### Cinematic Christian Ministry Website

The official web platform for **Jesus Saves Prayer Team (JSPT)**, founded by **Pastor V. Arul Dhas**. Designed as a high-performance, cinematic, and offline-first Christian ministry experience proclaiming the Gospel, call to prayer, and end-time prophetic message.

---

## 🌟 Key Features

- **Cinematic 3D Hero Section**: Real-time WebGL celestial particle field, volumetric heavenly light rays, and glowing 3D cross with mouse and scroll parallax powered by Three.js.
- **“JESUS IS COMING SOON” Proclamation**: Word-by-word animated headline sequence and prophetic end-time warning cards.
- **Bilingual English & Tamil Support**: Native script rendering and instant language switching for Tamil and English scriptures, sermon titles, and service times.
- **Pr. V. Arul Dhas Ministry & Family**: Highlighting the founder's 154K+ subscriber YouTube ministry, family dedication, and 24/7 prayer calling.
- **Interactive Community Prayer Wall**: Lift up prayer requests, celebrate answered praise reports, and stand in agreement with local "I Prayed" counters.
- **Direct WhatsApp Pastoral Link**: 24/7 prayer submission directly opening WhatsApp at `+91 94899 19343` with pre-formatted prayer briefs without paid messaging APIs.
- **Live Prayer Timetable**: Interactive countdown timer to upcoming Friday Fasting (10 AM - 9 PM), Saturday Kids Anointing (5 PM - 6 PM), and Sunday Worship (10 AM - 1 PM).
- **Offline-First PWA**: Built-in Service Worker and Web App Manifest for complete offline access to Bible verses, schedule, and ministry content.
- **Static-First Architecture**: 100% free open-source stack with no required backend, no database, and no cloud storage.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production static bundle for deployment
npm run build
```

The output in `dist/` is 100% static and can be deployed directly to Cloudflare Pages, GitHub Pages, Vercel, Netlify, or any static web host.
